# Marboma – custom code voor Webflow

Site-brede CSS en JavaScript voor marboma.webflow.io, ingeladen via jsDelivr.

## Bestanden
- `css/marboma.css` – underline hover, marquee, tabs, review, form validation, Vimeo
- `js/marboma.js` – Vimeo achtergrondvideo, highlight text, marquee, tabs, parallax, review slider, form validation

## In Webflow
Head Code:
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/niice-nocode/marboma@v1.0.0/css/marboma.min.css">

Footer Code (na GSAP, ScrollTrigger, SplitText en Vimeo Player API):
<script src="https://cdn.jsdelivr.net/gh/niice-nocode/marboma@v1.0.0/js/marboma.min.js"></script>

## Nieuwe versie
1. Pas de bestanden aan en commit.
2. Maak een nieuwe release/tag (bijv. v1.0.1).
3. Verander in Webflow het versienummer in beide regels en publiceer.
